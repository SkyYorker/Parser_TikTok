# Парсер TikTok - Тушь для ресниц

Парсер для сбора популярных роликов TikTok о туши для ресниц за последние 7 дней.

## Возможности

- Поиск роликов по ключевым словам и хештегам
- Фильтрация по дате публикации (последние 7 дней)
- Дедупликация роликов
- Экспорт в CSV и Google Sheets
- Обход антибот защиты TikTok

## Установка

### Требования

- **Python 3.8 или выше** (проверьте версию: `python --version` или `python3 --version`)

### 1. Клонирование репозитория

```bash
git clone https://github.com/SkyYorker/Parser_TikTok
cd Parser_TikTok_test
```

### 2. Создание виртуального окружения

Рекомендуется использовать виртуальное окружение для изоляции зависимостей:

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Linux/Mac:**
```bash
python3 -m venv venv
source venv/bin/activate
```

После активации виртуального окружения в начале строки терминала появится `(venv)`.

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Установка браузеров для Playwright

```bash
playwright install chromium
```

### 5. Настройка Google Sheets (опционально)

Если вы хотите использовать экспорт в Google Sheets:

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите Google Sheets API
3. Создайте Service Account и скачайте JSON ключ
4. Поделитесь таблицей Google Sheets с email из Service Account
5. Создайте файл `.env` на основе `.env.example`:

```env
GOOGLE_SHEETS_CREDENTIALS_PATH=path/to/credentials.json
GOOGLE_SHEETS_SPREADSHEET_ID=your_spreadsheet_id_here
GOOGLE_SHEETS_WORKSHEET_NAME=Тушь TikTok
```

## Использование

### Базовый запуск

```bash
python main.py
```

Парсер автоматически:
- Ищет ролики по всем ключевым словам и хештегам
- Фильтрует по дате (последние 7 дней)
- Удаляет дубликаты
- Экспортирует данные в CSV файл

### Настройка параметров

Отредактируйте файл `config.py` для изменения:
- Ключевых слов и хештегов
- Задержек между запросами
- Минимального количества роликов
- Периода поиска

## Структура данных

Экспортируемая таблица содержит следующие колонки:

1. **Ссылка на ролик** - прямая ссылка на видео
2. **Описание** - текст описания ролика
3. **Просмотры** - количество просмотров
4. **Лайки** - количество лайков
5. **Дата публикации** - дата и время публикации
6. **Хештеги** - список хештегов из описания

## Решение сложностей

### Антибот защита TikTok

**Проблема:** TikTok использует сложную систему защиты от ботов, включая Cloudflare, капчи и проверку поведения пользователя.

**Решение:**
- Использование Playwright с реальным браузером Chromium
- Имитация человеческого поведения: случайные задержки (2-5 секунд), прокрутка страницы
- Настройка User-Agent для имитации обычного браузера
- Отключение автоматизированных признаков (`--disable-blink-features=AutomationControlled`)

### Лимиты и блокировки

**Проблема:** TikTok может блокировать IP-адреса при слишком частых запросах.

**Решение:**
- Реализованы случайные задержки между запросами (2-5 секунд)
- Обработка ошибок с повторными попытками (до 3 раз)
- Сохранение промежуточных результатов для возможности возобновления
- При необходимости можно добавить ротацию прокси (требует дополнительной настройки)

### Поиск по датам

**Проблема:** Публичный поиск TikTok не всегда поддерживает точную фильтрацию по дате публикации.

**Решение:**
- Сбор всех найденных роликов по запросам
- Парсинг даты публикации из метаданных каждого ролика
- Фильтрация собранных данных по дате (последние 7 дней)
- Поддержка различных форматов дат (абсолютные и относительные: "2 часа назад", "3 дня назад" и т.д.)

### Дедупликация

**Проблема:** Один и тот же ролик может попасть в результаты по разным запросам (ключевое слово + хештег).

**Решение:**
- Использование множества (set) для хранения уникальных ID роликов
- Извлечение ID из URL ролика (формат: `/video/1234567890`)
- Проверка уникальности перед добавлением в результаты
- Гарантирует минимум 20 уникальных роликов без дублей
